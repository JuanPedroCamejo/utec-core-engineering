# Python - Functions and Modules

## Description

This directory contains Python functions that demonstrate character
processing, ASCII conversion, and the use of reusable functions.

## Files

### islower.py

Defines the `islower(c)` function.

The function checks whether a character is a lowercase ASCII letter.
It returns `True` if the character is between `a` and `z`, and `False`
otherwise.

### uppercase.py

Defines the `uppercase(str)` function.

The function converts lowercase ASCII letters to uppercase using
`ord()` and `chr()`. It preserves uppercase letters, numbers, spaces,
and punctuation.

The function prints the resulting string followed by a newline.
It does not return a value.

## Requirements

- Python 3
- No external libraries
- Executable Python files
- PEP 8 style compliance
